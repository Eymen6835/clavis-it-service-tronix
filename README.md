# Clavis IT Service – Website (Tronix Design)

Statische, DSGVO-konforme Website für **Clavis IT Service** (Inhaber: Eymen Kumaru, Mannheim).

## Merkmale

- **9 Seiten:** `index.html`, `geschaeftskunden.html`, `leistungen.html`, `preise.html`, `ueber-mich.html`, `kontakt.html`, `fernwartung.html`, `impressum.html`, `datenschutz.html`
- **Datenschutzfreundlich:** Keine Cookies, keine externen Schrift- oder Icon-CDNs, keine Analyse-/Tracking-Skripte; lokale `.woff2`-Schriften (`Space Grotesk`, `Schibsted Grotesk`, `Inter` unter SIL OFL 1.1)
- **Interaktive Funktionen:** Wartungsvertrags-Kalkulator, Preis-Tabs, Dark/Light-Mode (`localStorage` `clavis-theme` ausschließlich bei aktivem Klick), TeamViewer-QuickSupport-Systemerkennung, mobile Schnellkontaktleiste
